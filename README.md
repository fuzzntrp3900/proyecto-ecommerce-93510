# 🧩 HCS e-commerce

**Helix Carriers & Sleeves (HCS)** es una tienda online  que ofrece bolsos, carteras, estuches y artículos de viaje confeccionados en cuero de alta calidad y costuras reforzadas. Nuestros productos son muy resistentes para que puedas portar tus pertenencias de forma segura a donde sea que vayas.
## 🛠️ Tecnologias Implementadas:

- 🎨[Bootstrap5](https://getbootstrap.com/)
- 📦 **[React Icons](https://react-icons.github.io/react-icons/)** 
# 🎛️ Componentes:

- **Navbar:** contiene el brand de la tienda, las categorias y el carrito con el contador de items.
- **CartWidget:** componente que representa el carrito y el badge de conteo de items.
- **ItemListContainer:** es el contenedor principal que almacena el titulo de la app y proximamente el listado de productos.
## 🚀 Configuracion/Ejecución:

1. clonar el repositorio:
```bash
git clone https://github.com/fuzzntrp3900/mi-ecommerce-custom.git
```

2. instalar las dependencias:
```bash
#instala la carpeta node_modules para correr el proyecto
npm install
```

3. ejecutarlo:
```bash
#abre el enlace local del proyecto en el navegador
npm start 
```
